## 一、整体架构

## 二、各模块需求详述

### 2.1 我的（个人中心）

#### 个人主页

- **员工信息卡片**：头像（可更换，带相机图标）、姓名、职级标签（如"高级经理"，橙色）、脱敏手机号（138\*\*\*\*8888）、认证数
- **角色标识**：大按钮样式展示角色（如"店长"，粉红色渐变）
- **我的荣耀**：三列展示 — 我的等级、工龄勋章、员工商城（右侧"全部荣耀 >"可跳转）
- **公告区**：喇叭图标 + 滚动公告内容

#### 设置子页面

- 修改密码（旧密码/新密码/确认密码）
- 头像更新（拍照/相册选择/裁剪，支持 1:1、3:4、4:3）
- 切换账号（账号列表单选）
- 用户协议及隐私政策

### 2.2 工作台

#### 工作台首页

- 顶部：门店名称 + 搜索图标 + 设置图标
- 当前门店显示（带勾选状态，可切换）
- 左侧垂直导航 5 个模块图标
- 右侧内容区根据选中模块展示对应内容

#### 工作台上半部分 — 6 大核心指标

每个指标页面结构统一：

| 指标 | 格式 | 图表 | 详情列表字段 |
|------|------|------|-------------|
| 新客 | 数量（99） | 折线图 | 日期、客户、实收业绩 |
| 项目数 | 数量（99） | 折线图 | 日期、客户、划卡数、项目数 |
| 客流 | 数量（99） | 折线图 | 日期、客户、到店次数 |

**通用筛选**：门店选择（下拉）+ 日期范围选择（日历）

**详情页**（点击列表行跳转）：
- 新客/实收业绩详情：销售日期、顾客电话、顾客姓名、顾客类型、顾客来源、所属品项、项目服务、销售数量、销售价格、优惠金额、应付金额、商品备注、抵持转金、实收金额、欠款金额、不达单次费用转入待转金、实际可用次数
- 项目数/客流/实耗详情：服务日期、顾客电话、顾客姓名、顾客类型、预约技师、服务时间、服务项目、划卡次数、剩余次数
- 卡数详情：门店、日期、客户、售卡人

#### 目标设置与分配（工作台-0718 子页面集）

支持多维度目标设置与分配：
- 设置目标-实收 / 分配业绩
- 设置目标-消耗 / 分配流程
- 设置目标-卡数 / 分配卡数
- 设置目标-客流 / 分配客流
- 设置目标-项目 / 分配项目
- 设置目标-新客 / 分配客户

#### 上岗预览

- 导航栏："上岗情况"
- 筛选：搜索员工 + 日期选择
- 排班表格：时间段（9:00-13:00 / 13:00-18:00 / 18:00-23:00）、员工列表、备注（替班信息）

#### 预约预览

- 导航栏："预约情况"
- 统计："今日已预约 N 单"
- 筛选：搜索员工 + 日期选择
- 预约卡片：预约人、预约技师、预约时间、预约项目、详情入口

### 2.5 开单流程（6 种单据）

#### 2.5.1 销售单

**完整流程**：选客户 → 选商品 → 填写销售信息 → 收款 → 营业额分配 → 提交

**商品选择页**：
- Tab 切换：促销方案 | 疗程卡项 | 家居单品 | 充值卡金 | 组合套餐
- 搜索框 + 项目列表（标签、名称、价格、配发时长、"选购"按钮）

**销售单表单**：
- 销售日期、顾客电话、销售顾问
- 销售类型（下拉，如"首回一次"）
- 添加项目（点击添加）
- 服务类型来源
- 销售数量、销售金额、优惠金额、折扣价格
- 商品备注
- 实付金额、未付金额
- 底部："新增" | "删除" | "确定"

**欠款处理**：
- 显示用户历史欠款（金额大字号高亮，如 6787.00）
- 欠款明细列表：订单编号、已付金额、成单时间、项目名称
- 操作按钮："开新单" | "确认收款"

**收款方式**：
- 线下现金支付、线下扫码支付、线下刷卡支付
- 微信支付、支付宝

**营业额分配**：
- 按部门分组：美容部、养生部、推广部、品项部
- 每部门员工表格：员工编号 | 员工姓名 | 职位 | 分配个人金额
- 可添加员工（"+"按钮）

#### 2.5.2 转换单

**用途**：将客户已购项目（A）转换为其他项目（B），处理差价

**完整流程**：选客户 → 选转出项目(A) → 选转入项目(B) → 差价计算 → 支付确认 → 营业额分配 → 提交

**基础信息**：
- 对换日期、顾客电话（输入+获取）、顾客姓名、顾客来源
- AB 转换单号、销售单类型
- 促销方案选择

**A 表（转出项目）字段**：
销售流水号、产品库、疗程项目编号、品项分类、项目名称、单位、卡项总次数、实际售价、是否赠送、有效日期、单次价格、剩余次数、剩余未消耗、退次数、退消耗、协商金额

**B 表（转入项目）字段**：
销售流水号、产品库、疗程项目编号、品项分类、项目名称、单位、疗程服务次数、售价、销售数量、优惠（含金券抵扣）、销售金额、协商金额、应收金额、实收金额、可服务次数、赠送、有效日期、单次价格、顾客欠款、备注

**差价处理**：
- 转换数量、转换价格 × 单价 = 转换金额
- 是否折旧费（复选）+ 应退折旧费金额
- 支付方式：线下扫码 / 线下现金 / 线上回圈

**营业额分配**（员工字段）：
员工编号、员工姓名、职位序列、职位、个人业绩1/眉眼/灸、个人业绩2/层、祛斑点痣业绩、单品业绩、核算

#### 2.5.3 退款单

**用途**：处理客户退款，区分服务项目退款和商品退款

**完整流程**：选客户 → 选退款项目 → 退款计算 → 退业绩 → 营业额回退确认 → 提交

**基础信息**：
- 退款日期、退款类型（售后）、顾客电话（输入+获取）、顾客姓名、顾客来源
- 凭证编号、退款编号
- "查询往期消费"链接

**退款项目选择**：
- 商品搜索框
- 可退商品列表：商品名称、可用次数、剩余未消耗金额
- 支持多选，底部"+ 添加"

**退款项目字段**：
销售流水号、疗程项目编号、产品类型、品项分类、项目名称、单位、赠送、有效日期、单次价格、合计已消耗、剩余次数、剩余未消耗、退款次数、退消耗

**退款三种情况**：
1. **全退**：商品全部退回，不涉及优惠分配
2. **部分退（按件数）**：已出售数量 > 退回数量，生成新的变更订单
3. **部分退（按金额）**：按金额折算退款

**金额计算**：
- 销售数量、销售单价、销售金额
- 充值卡金支取（红色标注）
- 优惠金额、增纳金额
- 实收金额、应退金额
- 折算扣费
- 实退金额

**退业绩**：关联员工的业绩需同步回退

#### 2.5.4 回款单

**用途**：处理客户未付尾款/欠款

**完整流程**：选客户 → 查看欠款列表 → 选择回款项目 → 录入回款信息 → 营业额分配 → 提交

**欠款列表页**：
- 客户欠款卡片列表（每张显示欠款金额大号、订单编号、已付金额、成单时间）
- 支持勾选多个欠款项
- 操作："开新单" | "一起回款"
- 灰色项表示已付清（保留但不可操作）

**回款信息录入**：
- 每个项目独立区块：所属品牌、项目服务、销售数量、销售价格、应付金额
- 实收金额、充值卡金支取（红色标注，输入框）
- 订单金额、实际可用次数
- 增纳金额（输入框）
- 回款后订单余额、回款后欠款额/卡次
- 次回款额/数量/卡次、商品备注
- 底部汇总：充值卡金支取合计 + 增纳金额合计

**组合套餐回款**（独立流程）：
- 套餐名称 + 橙色标签
- 销售数量、销售价格、欠款金额
- 充值卡金支取、增纳金额
- 增纳后欠款金额（自动计算）

#### 2.5.5 取货单

**用途**：实物商品提货

- 销售日期、顾客电话（带"修改"按钮）、顾客姓名、顾客类型
- 商品列表（radio 可选）：
  - 产品名称、剩余未取数量
  - 数量调节器（- N +），不可超过剩余未取
- 底部："确定"

**业务规则**：
- 关联原销售单中的实物商品
- 支持分次取货

#### 2.5.6 付款

- 顶部会员卡信息：卡号、余额、"取消会员"按钮
- 等待支付倒计时（180 秒）
- 订单摘要：商品件数 + 总金额
- 付款码展示区（二维码）
- 支付方式：微信支付 | 支付宝 | 二维码扫码
- 底部："返回" | "余额支付"

### 2.6 预约管理

#### 今日预约（甘特图视图）

- 筛选：门店选择 + 日期选择
- 统计："今日共 N 个预约，空闲 N 个时段"

  - 待确认：「确认预约」「取消」
  - 已确认：「顾客到访」「取消」
  - 服务中：「完成服务」

#### 预约详情

- 预约 ID、预约门店、预约时间、预约技师
- 顾客信息：姓名、顾客编号
- 项目信息：名称、编号、金额、消耗金额、划卡次数
- 状态时间线：
  - 预约时间 → 门店确认（点击"确认预约"） → 到店确认（点击"顾客到访"） → 服务完成（点击"完成服务"） → 取消时间

### 2.11 员工绩效

#### 绩效主页

- 门店筛选 + 员工筛选

**提成项目卡片（6 项）**：
| 卡数提成 | 手工费 | 自销实耗提成 |
| 自销业绩提成 | 他销业绩提成 | 退款扣提成 |

**明细切换**：卡数明细 | 手工实耗明细 | 业绩/消耗/退款

**提成模式**：普通提成 / 阶梯提成

**业绩汇总**：业绩合计 + 提成合计

**分类 Tab**：合计 | 销售 | 服务 | 他销他耗 | 生态合作

**明细列表**：服务项目名称、时间、提成金额、业绩金额、顾客姓名/电话、员工姓名、门店

### 2.12 经营数据

#### 经营数据首页（模块入口）

1. 客户回店率 → 保有会员、客户活跃度
2. 品项占比 → 品项销售数据、品项消耗数据
3. 经营动线 → 动线数据、各项持卡数
4. 人效分析 → 员工英雄榜、人效达标率、排名数据

#### 客户回店率

**保有会员**：
- 日期范围筛选
- 核心指标："保有会员人数 N 人"
- 列表：客户名称 / 到店次数 → 点击查看详情

**客户活跃度**：
- 月份选择
- 指标：回访人数、客淘率
- 统计：>1 次客户（人数、占比）、>2 次客户（人数、占比）
- 活跃客户列表 → 点击查看详情

#### 品项占比

**品项消耗数据**：
- 日期选择
- **环形饼图**：按品项分类占比（招牌/绝对招牌/拓牌等）
- 筛选下拉："全部"
- 列表：客户名称 / 消耗次数 / 消耗金额

**品项销售数据**：
- 结构同消耗，列表变为：客户名称 / 项目次数 / 实收金额

#### 经营动线

**动线数据**：
- 年份选择
- 表格：档位（消费层级）| 去年动线基数 | 去年基数今年被经营 | 今年动线人数
- 客户列表：客户名称 / 年度消费

**字段定义**（产品批注 #21）：
- 档位 = 消费层级（如 1-2999、3000-5999 等）
- 去年动线基数 = 去年该档位下的消费人数
- 去年基数今年被经营 = 该档位下去年消费的人中今年依旧来消费的人数
- 今年动线人数 = 该档位下今年新增的人数

**各项持卡数**：
- 日期选择
- **环形饼图**：按品项持卡占比
- 列表：客户姓名 / 剩余次数 / 剩余未消耗金额

#### 人效分析

**员工英雄榜**：
- 门店 + 日期 + 时间快捷（今日/本周/本月）
- 两个下拉筛选器：业绩类型（自销业绩等）+ 时间范围（<3 月等）
- 按部门分组列表（美容部/养生部/推广部）：
  - 每位员工：姓名、门店、已完成金额、月目标

**人效达标率**：
- 月份选择
- 表格：员工姓名 | 出勤天数 | 达标天数 | 达标率

**排名数据**：
- 区域选择（下拉）+ 日期 + 时间快捷
- 业绩类型筛选
- 表格：排名 | 目标 | 完成 | 达标率

## 四、通用 UI 规范

### 交互模式

- **工作台**：左侧垂直图标导航 + 右侧内容区
- **客户档案**：顶部多 Tab 横向滚动切换
- **筛选**：门店选择（下拉）+ 日期范围选择（日历），几乎所有数据页面通用
- **数据展示**：核心指标大数字 + 图表 + 详情列表，点击行跳转详情页
- **开单流程**：基础信息 → 项目明细 → 金额计算 → 营业额分配 → 收款/确认 → 提交

### 图表类型

| 类型 | 用途 |
|------|------|
| 折线图 | 时间趋势（新客、项目数、客流、卡数、实耗/实收业绩） |
| 环形饼图 | 占比分析（品项消耗占比、品项销售占比、持卡占比） |
| 甘特图/时间轴 | 预约管理（房间 × 时间段） |

### 颜色规范

- 金额数据：**红色**高亮
- 充值卡金支取：**红色**标注
- 状态标签：蓝色（预约中）、绿色（已确认）、灰色（已完成）、橙色（待确认）
- 角色按钮：粉红/珊瑚色渐变
- 职级标签：橙色

### 营业额分配（通用模板）

适用于销售单、转换单、退款单、回款单：
- 按部门分组（美容部、养生部、推广部、品项部）
- 每部门员工表格：员工编号 | 员工姓名 | 职位 | 分配个人金额
- 可添加/删除员工
- 提交按钮

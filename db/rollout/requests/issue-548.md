交接先于储值卡读写；源批次按到期/id预锁，积分退款按本单批次同序预锁，过期任务同序锁批次。现金快照只取已支付SOP，不取创建时尚未扣卡的预填received。

## 合入与部署的边界

PR 将业务代码和正式迁移一起合入 dev，不需要先迁共享库才能合入。合入本身不执行迁移或部署。部署时须先核验目标 journal 并执行 db:migrate，再只读审计，最后发布四端同版代码和小程序。

只读入口（必须显式目标连接串，按 db/AGENTS.md 的 host/port/dbname 与 query 覆盖参数断言）：

```bash
DATABASE_URL="$TARGET_DATABASE_URL" node db/scripts/audit-conversion-value-sources.js
```

该工具只读、输出缺口名单与完整性异常。历史 NULL/v1 或无确定批次事实的项目维持退款拦截；不得将“新功能可合入”写成“历史全量已修复”。有凭据的历史补建另用已确认映射、私有重放与独立评审交付，不在本次 DDL 中按现价/余额自动猜算。部署验收须分别记录新单流程、历史可退款/受保护范围和人工页面/真机实效。

## 一、整体架构

### 1.1 底部 TabBar

设计稿中存在两种方案，以高保真 UI 稿为准：

| Tab | 图标 | 说明 |
|-----|------|------|
| 首页 | 店铺图标 | 主页面，含 Banner、快捷入口、产品专区 |
| 预约 | 日历图标 | 预约入口 |
| 消息 | 气泡图标 | 消息中心（线框稿中为"凤御馆"） |
| 我的 | 人物图标 | 个人中心 |

> 备注：线框稿中 Tab3 为"凤御馆"（品牌介绍页），高保真稿改为"消息"。"凤御馆"降级为首页快捷入口跳转。

### 1.2 色彩方案

- **主色**：暖金/橙色（品牌色，Logo、选中态、强调按钮）
- **价格色**：红色
- **辅助色**：绿色（加购按钮、状态标签"空闲"）
- **背景**：白色为主，浅灰色用于分类侧边栏、卡片背景
- **风格**：高端美容/护肤品牌调性

## 二、页面需求详述

### 2.1 登录模块

#### 2.1.1 登录页（screen_002）

**个人中心未登录态：**
- 灰色圆形占位头像 + "登录/注册"文字，点击弹出登录弹窗

**登录弹窗（模态）：**
- 欢迎文字"欢迎登录！"
- 手机号输入框（placeholder "请输入电话号码"）
- 提示"未注册的手机号验证后将自动注册"
- 验证码输入框 + "获取验证码"按钮（橙色文字）
- 协议勾选："我已阅读并同意《免责声明》"
- 登录方式切换：微信登录图标、账号密码登录图标
- 橙/金色"登录"按钮

**交互要点：**
- 支持手机号+验证码登录、微信授权登录两种方式
- 未勾选协议时登录按钮置灰
- 微信登录触发 `getPhoneNumber` 获取手机号

#### 2.1.2 绑定门店页（screen_002 下半部分）

- 页面标题"请选择绑定门店"
- **门店选择**：下拉单选（凤御1店 / 凤御2店 / 凤御3店 / 凤御4店）
- **来源选择**：下拉单选（推广部 / 老带新 / 美团 / 抖音 / 转让店 / 自进 / 内部地推 / 第三方拓客）
- **宣传推广人**：文本输入框（选填）
- 底部"确定"按钮

### 2.2 首页（screen_003）

**导航栏：**
- 品牌 Logo「FENGYU 凤御美业」（金色凤凰图案）

**搜索栏：**
- 定位图标 + 城市名（如"昆明市"）
- 搜索框（placeholder "搜索"）
- 消息/客服图标

**Banner 轮播区：**
- 大幅横版广告图，支持左右滑动
- 文案示例："深度美肌护理体验"
- 底部标签：皮肤检测、深度清洁、面部按摩、专业服务
- 底部圆点分页指示器

**快捷入口区（金刚区，5个圆形图标）：**

| 入口 | 图标颜色 | 跳转目标 |
|------|----------|----------|
| 附近门店 | 橙红色 | 门店列表页 |
| 产品商城 | 深色 | 产品分类页 |
| 服务商城 | 绿色 | 护理项目分类页 |
| 推荐技术 | 黄色 | 技师列表页 |
| 优惠券 | 蓝绿色 | 优惠券页 |

**产品专区（左右分栏联动）：**
- **左侧分类导航**（纵向 Tab 列表）：
  - 面部肌能 → 好净润 / 好光彩 / 好精致 / 好轻松 / 好修复 / 好年轻
  - 身体肌能
  - 家居产品
  - 焕紫爱 / 冰蓝 / 黑金 / 翡翠
  - 全部 / 全部项目
- **右侧商品列表**：按分类分组，每组有分类标题标签
  - 商品卡片：商品图片 + 商品名 + 红色价格（¥369.00）+ 灰色原价（划线）+ 已售数量 + 绿色"+"加购按钮

**交互要点：**
- 左侧分类 Tab 与右侧商品列表联动滚动
- 点击商品卡片进入商品详情
- 点击"+"按钮加入购物车或直接下单

### 2.9 订单中心（screen_020 / 021 / 022）

**Tab 筛选栏**：全部订单 / 待付款 / 已付款 / 已预约 / 待服务 / 已服务

**订单卡片**：
- 门店名称 + 状态标签（右上角）
- 商品缩略图 + 名称 + 数量 + 服务人员
- 底部信息：服务时长 + 剩余次数

**各状态特殊操作：**
- 待付款：显示"付款"按钮
- 已付款：可查看套餐明细（展开子项目列表）
- 已服务：关联"去评价"入口

**订单详情页**：
- 订单编号、状态、创建时间
- 服务门店、服务技师、服务日期、服务时段
- 客户姓名、预约状态
- 订单商品明细（名称/数量/类型/单价/销售员工/辅助员工）
- 商品合计 + 整单优惠合计 + 订单总价
- 预约记录区（状态/时间/门店/项目/员工）

**订单状态流转：**
```
待付款 → (付款) → 已付款 → (预约) → 已预约 → (到店) → 待服务 → (完成) → 已服务 → (评价)
```

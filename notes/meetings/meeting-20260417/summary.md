# 凤御数据中心特邀会议 · 摘要

**2026-04-17** | 张凯 · 贺东群 · 夜航星 · 邵冬

## 最重大决定

**外部端（管理后台）的"数据中心"板块不再独立开发，改为将现有 BI 平台"分析师"嵌入管理后台**。

- 依据：数据中心设计图和分析师几乎一一对应；分析师本身支持缓存、图表、导出
- 收益：小程序/后台的账号权限可直接复用，无需在分析师另建用户体系
- 待办：张凯需尽快签完分析师合同（邵冬提醒）

## 小程序端定位

仅保留**简版看板**，展示关键指标，不放宽表明细：

- 单行不超过 3~4 列（参考 WorkFine 移动端"两列常态、四列极限"）
- 由贺东群从完整指标集中筛出"核心指标清单"发给夜航星评估

## 指标口径要点

| 指标 | 口径 |
|------|------|
| 会员注册人数 | 本月内单笔消费满 1990 元，动态 |
| 有效保有会员 | 前 3 个月（整月口径）至少到店一次，按月定格 |
| 本月一次/二次到店 | 在保有会员基础上实时统计 |
| 沉睡/冰冻/休眠 | 截止上月底的快照 |
| 当月激活 | 沉睡/冰冻/休眠本月又到店的人数 |
| 消费分档 | 筛选周期内累计消费，非历史累计；仅统计会员客；新增会员单列字段 |

## 权限分层

- 基层员工（美容师/养生师）不可见（"权限按组织单位划分，不细到客户颗粒度"）
- 店长看本店；其他门店排名只显示自己行与名次
- 行政经理 / 区域经理 / 总监 / 老板 / 财智部按组织层级向上放权

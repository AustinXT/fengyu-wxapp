# WorkFine 旧系统进销存逻辑

> 整理日期：2026-08-09
>
> 适用范围：WorkFine 旧系统的供应链、市场、门店三级进销存。
>
> 事实来源：需求方提供的《进销存逻辑》图及其文字说明；已留存的 WorkFine 只读元数据调研仅用于识别已核验的物理表和字段。
> 非来源：当前项目的库存、采购、订单或财务代码和数据库设计。本文件不描述、更不反推当前项目实现。

## 1. 核心结论

旧系统以**供应链、市场、门店**三级分别持有实时库存。报货类单据负责汇集需求和确定后续入库价格，**不直接增减库存数量**；实际库存仅由入库、出库、退货、调货、报损、盘点等库存单据变动。

市场既是供应链的采购方，也是门店的配货方：

```text
门店报货 -> 市场报货汇总/市场报货单 -> 采购订单
                                              |
供应链采购入库 -> 品项公司发货单 ----匹配----+-> 市场采购入库
                                                    |
市场库存（亦可来自自采、盘溢、调入、门店退货） -> 分院配货单 -> 门店入库
                                                                    |
                                                顾客领取 / 门店退货 / 门店报损 / 门店间调货
```

上图是业务关系的简写。单据是否可操作、审核者、价格和库存影响，以后续章节的明确规则为准。

## 2. 组织层级与库存边界

| 层级 | 主要职责 | 图中库存与财务结果 |
| --- | --- | --- |
| 供应链 | 向市场供货；发货；处理市场退货；处理员工购、非凤御市场出库、内部领用等 | 有实时库存；有出库收入确认、出库成本结转 |
| 市场 | 汇总门店需求并向供应链采购；自行采购并向门店配货；处理市场内相关出入库 | 有实时库存；有市场货款结算单、分院货款结算单 |
| 门店（分院） | 发起报货需求；收货、向顾客发货、退货、报损及门店间调货 | 有实时库存；图中未列门店层的独立财务结算单 |

库存不可跨层混用：市场采购入库增加的是市场库存，分院入库增加的是对应门店库存；门店间调货是一个门店出库、另一个门店入库的一对动作。

## 3. 产品主数据与价格

### 3.1 全产品资料表

《全产品资料表》是报货和库存单据的产品基础资料。每种产品维护下列多套价格，不能将它们混为同一个销售价：

| 价格 | 使用场景与规则 |
| --- | --- |
| 供应链采购价（成本） | 供应链层采购成本。 |
| 市场进货价 | 市场报货单的默认取价。市场存在报货福利时，在此基础上形成实际单价。 |
| 门店进货价 | 分院配货的价格基础；门店报货单无需展示该价格。 |
| 市场员工购价 | 市场员工购买产品时取用。它不同于销售单中的“员工购”；该交易不计入门店营收，直接是市场收入。 |
| 零售价 | 面向顾客的标价，仅登记；不影响销售单。 |
| 核算价 | 用于核算市场进货价。例如顾客售价 5,980 元、核算价 4,000 元、市场折扣为 25%，则市场进货价为 1,000 元。 |

从示例可确认，市场进货价的计算口径为“核算价乘以市场折扣率”。资料没有定义“25%”在界面中的录入格式（`25` 或 `0.25`），实际字段类型与换算应以 WorkFine 元数据和历史单据复核为准。

### 3.2 市场报货福利方案

《市场报货福利方案》补充而不改写产品主数据中的原始价格。供应链在特定时间、特定产品、特定数量条件下，可以设置组合优惠或阶梯优惠金额。

市场报货时可提取满足条件的优惠单，得到“单价优惠”。市场报货单的实际单价为：

```text
实际单价 = 市场进货价 - 单价优惠
```

福利方案本身不改变库存数量，也不直接修改产品资料中的市场进货价。

## 4. 报货与供应链采购

### 4.1 报货单据的共同边界

图中将报货单据单列，并标明：**不影响库存数量，但是影响入库单价**。因此，报货、汇总、采购订单、优惠提取等是需求与价格确定过程；库存变动必须等到相应入库或出库单完成。

### 4.2 从门店需求到市场采购

1. 门店通过“门店报货单选择单”视图形成《分院报货单》。全产品资料和自采产品信息均可成为可报货的产品来源。
2. 市场按日期提取本市场下各门店的报货详情，形成《市场报货单》。图中同时存在《市场报货单汇总》，用于归集门店需求。
3. 门店报货汇总数量只是市场采购的参考，不等于实际采购数量。市场应同时查看实时库存，并由人员手工填写实际采购数量。
4. 市场报货单通常取全产品资料中的市场进货价；符合福利方案时，提取单价优惠，计算实际单价。
5. 以实际采购数量和实际单价计算本期应付货款；市场据此向供应链付款。
6. 图中“品项公司自己报货需求”和《市场报货单汇总》共同进入《采购订单》。该图没有给出二者是否为同一单据的不同视图，不能据此合并为一个实体。

市场货款结算单是市场层的财务单据，用于结算市场向供应链采购形成的货款。

### 4.3 供应链发货与市场采购入库

1. 供应链侧有《采购入库单》与《品项公司发货单》；后者需要与《市场报货单》匹配，可查看市场报货对应的发货进度。
2. 《品项公司发货单》的发货数量可以大于《市场报货单》的采购数量，超出部分是赠送部分。
3. 品项公司发货单不记录单价和货款金额。
4. 市场只能在已有《品项公司发货单》时创建《市场采购入库单》。该入库单才使货物进入市场库存。
5. 市场财务在入库发现问题时，只能联系供应链会计撤回品项公司发货单，不能自行驳回该流程。

供应链侧的《出库收入确认》和《出库成本结转》是图中对应发货出库的财务处理；图中没有给出它们的触发时点、会计科目或与哪一个单据的一对一关系。

## 5. 市场自采与市场库存

### 5.1 自采产品

《自采产品信息单》《自采产品入库》均由市场财务自行完成。它服务于未经过供应链的物料，例如一次性床单、耗材、定制水杯、转让门店产品等。

自采产品入库后，市场可以像普通产品一样向门店配货，并据此核算门店货款。图中自采产品信息可被门店报货选择视图使用，但没有明确自采产品是否必须先由门店报货才能配货。

### 5.2 市场库存的入出方向

| 方向 | 图中市场层单据 | 已明确的业务含义 |
| --- | --- | --- |
| 入库 | 市场采购入库单 | 基于品项公司发货单，将供应链发货入到市场库存。 |
| 入库 | 自采产品入库 | 市场财务自行采购的产品或耗材入库。 |
| 入库 | 市场产品盘溢单 | 增加市场库存的盘点差异单。 |
| 入库 | 市场间调货入库 | 其他市场调入。 |
| 入库 | 分院退货单 | 门店退回市场的产品入市场库存。 |
| 出库 | 分院配货单 | 市场向门店配货，构成门店入库的来源。 |
| 出库 | 市场退货单 | 市场退回供应链；市场可制单，但须供应链审核。 |
| 出库 | 市场报损单 | 市场层损耗出库。 |
| 出库 | 员工购出库 | 市场员工购买产品的出库；收入归市场，不归门店。 |
| 出库 | 市场间调货出库 | 调拨至其他市场。 |

市场层实时库存由上述已完成的库存单据累计形成。图中未给出盘点单、报损单、调货单的审批状态和是否允许撤销，不能自行补充状态机规则。

## 6. 市场向门店配货与门店库存

### 6.1 分院配货与门店入库

《分院配货单》与《分院报货单》关联，可查看门店报货的发货进度。它的发货数量可以大于分院报货数量，超出部分是赠送部分。

配货单必须记录门店进货价、数量、单价优惠、应付货款。这些数据共同确定本批货物给门店的真实单价；此后的门店退货和门店间调货都以该真实单价为准。资料没有单独给出门店真实单价的公式，因此以配货单实际记录的价格和应付货款为准，不应在新系统中仅根据当前产品主数据重算历史批次价格。

《分院入库单》是门店实际收货入库单。图中从分院配货单连到分院入库单，表明其是门店库存增加的来源。

市场层的《分院货款结算单》用于结算门店因配货形成的货款。

### 6.2 门店库存的入出方向

| 方向 | 图中门店层单据 | 已明确的业务含义 |
| --- | --- | --- |
| 入库 | 分院入库单 | 接收市场配货，增加对应门店库存。 |
| 入库 | 分院间调货入库 | 接收同市场内其他门店调入的货物。 |
| 入库 | 顾客退货单 | 顾客退回的产品重新进入门店库存。 |
| 出库 | 顾客领取单 | 门店向顾客交付产品。 |
| 出库 | 分院退货单 | 门店退货给市场；门店可制单，但须市场财务审核。 |
| 出库 | 分院报损单 | 门店损耗出库。 |
| 出库 | 分院间调货出库 | 调拨至同一市场内的其他门店。 |

门店之间只允许在**同一市场内部**调货。门店端小程序展示的入库、出库等库存表单不需要展示金额，即使后台单据为核算和结算保留金额。

## 7. 供应链层库存单据

图中供应链层存在独立实时库存。除《采购入库单》《品项公司发货单》外，还列出以下出库单据：

| 单据 | 图中给出的用途/方向 |
| --- | --- |
| 员工购出库 | 员工购买产品的供应链层出库单。与市场员工购的归属关系未在资料中说明。 |
| 非凤御市场出库单 | 向非凤御市场出库。 |
| 库存产品转换单 | 库存产品转换出库。具体转换规则未提供。 |
| 内部领用单或者盘溢单 | 图中列为供应链层出库单。该名称与通常盘点方向可能不一致，应以 WorkFine 原表名称和字段含义复核，不应据名称擅自改为盘亏或盘溢。 |

供应链层的市场退货审核，是市场退货能生效的前置条件。资料未说明市场退货审核通过后是直接回到供应链库存，还是还需要另建入库单；此点须从 WorkFine 原单据关联和数据记录确认。

## 8. 单据影响矩阵

| 单据类别 | 库存数量 | 价格/金额 | 主要关联或约束 |
| --- | --- | --- | --- |
| 产品主数据、市场报货福利方案 | 不影响 | 提供多层价格、优惠条件 | 福利不改原始价格。 |
| 门店/市场报货、汇总、采购订单 | 不影响 | 决定后续市场入库的价格和市场应付货款 | 市场采购数量需参考库存后手工确定。 |
| 品项公司发货单 | 作为市场采购入库前置条件 | 不含单价、货款 | 可超市场报货数量，超出可为赠送。 |
| 市场采购入库、自采入库、调入、门店退货 | 增加市场库存 | 按来源单据保留必要价格信息 | 市场采购入库必须已有品项公司发货单。 |
| 分院配货、市场退货、市场报损、市场员工购、市场调出 | 减少市场库存 | 分院配货决定门店真实单价；员工购为市场收入 | 市场退货需供应链审核。 |
| 分院入库、顾客退货、门店调入 | 增加门店库存 | 小程序不展示金额 | 分院入库来源于市场配货。 |
| 顾客领取、门店退货、门店报损、门店调出 | 减少门店库存 | 后续退/调以配货真实单价为准 | 门店退货需市场财务审核；门店间调货限同市场。 |
| 供应链/市场财务结算单 | 不改变图示库存 | 完成货款、收入或成本结算 | 具体会计规则未提供。 |

| 门店辅助对象 | 门店报货单选择单视图，以及其与分院报货单、自采产品信息的实际提取关系。 |

回查时应至少记录：模板 ID、模板当前名称和历史名称、主表/明细表名、`RID` 关联、单据号字段、市场/门店字段、产品字段、数量字段、批号/有效期、赠送标志、原价/优惠/实际价/货款字段、审核/撤回状态字段及来源单据号字段。查询结果应以“业务名称 + 模板 ID + 物理表名”保存，不能只按模板名称匹配。

## 11. 明确未提供、不得擅自补全的规则

- 市场报货、采购订单、发货、入库、配货、收货的完整状态机及各状态的可撤销条件。
- 赠送数量在市场采购入库和分院配货中的单价、货款、成本结转处理。
- 市场退货审核通过后的供应链库存落账方式。
- 市场间调货是否有市场范围限制、双方确认流程和结算规则。
- 市场产品盘溢、供应链“内部领用单或者盘溢单”的精确库存方向与审批规则。
- 供应链、市场、门店三层实时库存的计算口径（是否按批次、有效期、赠送标记、审核状态过滤）。
- 出库收入确认、出库成本结转、市场货款结算、分院货款结算的触发时点和会计计算规则。

这些内容应在获得 WorkFine 模板字段、历史数据样本和业务确认后，作为补充章节添加；在此之前，不能用当前项目的实现或常见 ERP 惯例替代旧系统事实。

# 2026-03-04 需求沟通会议摘要

> 参会人：张凯（客户方）、邵冬（项目经理）、夜航星（开发）

## 核心决策

1. **员工端 UI 参考原始原型图改版**，首页展示业绩、消耗、客流、新会员等简单汇总数据，不涉及复杂计算
2. **数据看板分工**：简单指标在小程序展示，复杂分析跳转决策分析系统；需列清单明确划分
3. **快捷按钮方案**：预设全部筛选条件，默认展示前 6 个，支持展开查看全部，自适应布局
4. **订单类型扩展**：销售单下新增体验单（售前体验卡）和内部单（员工/家属半价），需打标记以便数据分析时剔除
5. **优惠券统一设计**：现金券、项目券、折扣券抽象为统一模型，先出一版再迭代
6. **用户体系迁移**：未来所有员工档案和顾客档案都在小程序管理，不再依赖 WorkFine
7. **顾客分类**：多维度标签（粉丝/铁粉/黑钻），按年度消费金额滚动计算等级

## 关键指标定义

| 指标 | 定义 |
|------|------|
| 客流 | 服务单数量，一人一天算一次 |
| 客量 | 按日期+顾客编号去重，一人一月算一次 |
| 新会员 | 首次消费达 1980 元 |
| 业绩 | 收款金额汇总（不限付款方式） |
| 消耗 | 服务单划卡单价汇总 |

## 角色权限

- 美容师：仅看自己数据
- 店长：看整店数据，拿整店业绩
- 区域总监：默认看区域数据，可筛选具体门店

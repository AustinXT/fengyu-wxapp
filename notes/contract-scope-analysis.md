---

## 变更说明

依据合同第五条及附件一《项目开发功能清单》，以下功能不在原合同约定范围内。经双方协商，分为**计费变更**（需额外支付开发费用）和**协商变更**（双方协商纳入本期交付、不另行收费）两类。

---

## 一、计费变更

以下功能超出合同附件一约定范围，依据合同第 5.2.1 条按 1,500 元/人/工作日 收费。

### 1.1 员工端新增功能

| 序号 | 变更需求 | 详细描述 | 人天 |
|------|---------|---------|------|
| S1 | 工作台仪表盘 | 今日分成卡片（今日/本月/上月三行，含订单数与服务单数）、月度业绩日历（7×6 网格，按日展示分成金额，≥1000 显示 k 格式）、6 种待办计数与快捷跳转（预约待确认/服务单待推进/待确认收款/待确认订单/待提成分配/待审批解绑） | 3 |
| S2 | 营业额分配 | 已支付订单的营业额分配系统：支持跨部门分配（各部门独立计算）、4 种销售分类（自采自销/他销自耗/他销他耗/生态合作）、从 PG 提成比例矩阵自动查询费率、可编辑窗口控制（顾客扫码后锁定）、智能推荐候选人、待分配列表 | 4 |
| S3 | 数据看板 | 5 项经营指标展示（客流/客量/新会员/业绩/消耗），支持今日/本月/上月 3 个时间维度切换，美容师仅看个人数据、店长看整店数据 | 3 |
| S4 | 提成展示与绩效明细 | 从工作台分成卡片下钻的绩效明细页：6 种提成项目卡片（卡数提成/手工费/自销实耗/自销业绩/他销业绩/退款扣提成）、5 分类 Tab（合计/销售/服务/他销他耗/生态合作）、双维度提成模型（销售提成+服务提成独立计算） | 3 |
| S5 | 内部单（员工消费） | 员工/家属消费按 SKU 价格×0.5 自动计算半价，订单标记 sale_order_type='内部'，统计时不算顾客数（客流/客量排除）、不计入会员等级升级消费 | 1.5 |
| S6 | 体验单 | 限选体验卡商品的特殊开单类型，独立 sale_order_type='体验'，不计入普通业绩统计 | 1 |
| S7 | 顾客管理增强 | 顾客列表页 6 统计卡片（活跃/即将流失/流失/沉睡/本月生日/下月生日）、标签筛选（按年消费 tier 分类）、顾客等级体系（粉丝/铁粉/黑钻，按年度消费金额滚动计算） | 3 |
| S8 | 逐项优惠 | 员工端开单购物车支持 per-item discount（逐项输入优惠金额），上限校验（discount ≤ price × quantity） | 1 |
| | **员工端小计** | | **19.5** |

### 1.3 管理后台（Web 端）

合同附件一仅约定客户端小程序与员工端小程序，未涉及 Web 管理后台。以下为独立开发的管理后台功能。

| 序号 | 变更需求 | 详细描述 | 人天 |
|------|---------|---------|------|
| A1 | 商品目录管理 | 品项分类+商品(SPU)+规格(SKU) 三层 CRUD，支持有效期叠加校验（商品+SKU 均有效才展示）、套餐管理（is_bundle）、封面图与详情图上传 | 5 |
| A2 | 提成比例矩阵配置 | 按 市场×订单类型×角色类型×销售分类×金额阶段 五维度配置提成比例，金额阶段不可重叠，物理删除（快照在 sale_allocations 中保留） | 3 |
| A3 | 业务操作（adminApi） | 在 Web 端独立实现员工端全部核心业务操作（开单/订单管理/营业额分配/服务单/预约），向导式大屏表单，JWT 认证，可打印二维码 | 6 |
| A4 | 优惠券管理 | 券模板 CRUD（现金券/项目券/折扣券），支持配置满减条件、适用商品/分类范围、发放总量、有效期模式（固定日期/领取后N天） | 2 |
| | **管理后台小计** | | **16** |

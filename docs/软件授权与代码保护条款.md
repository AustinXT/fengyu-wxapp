# 软件授权与代码保护条款（模板）

> **用途**：管理后台（fengyu-admin）以编译后的 Docker 镜像形式部署到客户自有服务器时，
> 随交付/服务合同附上的授权与禁止反编译条款。
>
> **性质**：本文件是技术团队提供的**条款草案模板**，非法律意见。正式对外签署前，
> 务必交由公司法务或执业律师审定、并与主合同的「软件许可 / 知识产权」章节合并。
>
> **为什么需要它**：交付物虽为编译压缩后的产物（不含 TypeScript 源码、不含 source map），
> 但 Node/JavaScript 在技术上无法做到「绝对不可读」。客户对自有服务器拥有 root 权限，
> 理论上可提取镜像内的压缩代码。因此 IP 保护必须「技术措施 + 法律约束」双管齐下——
> 本条款承担法律约束这一半。

---

## 一、定义

- **「本软件」**：指甲方（软件提供方）交付的「凤御美业管理后台」及其全部组成部分，
  包括但不限于编译后的目标代码、容器镜像、配置模板、数据库结构定义、随附文档。
- **「目标代码」**：指经编译、打包、压缩后用于运行的程序文件，不含人类可读的原始源代码。
- **「源代码」**：指甲方以 TypeScript / JavaScript 等高级语言编写的、含完整注释与可读
  标识符的原始程序文本。甲方**不向乙方交付源代码**。
- **「乙方」**：指被许可使用本软件的客户。

## 二、授权范围（许可而非转让）

1. 甲方仅授予乙方在**约定的服务器与门店范围内**、为乙方**自身经营目的**使用本软件目标代码的
   非独占、不可转让的许可。本软件的著作权及一切知识产权始终归甲方所有，本协议不构成任何
   权利转让。
2. 许可范围**不包括**对源代码的任何权利。乙方理解并确认：甲方交付的是编译后的运行产物，
   甲方没有义务提供源代码。

## 三、禁止行为（核心）

未经甲方事先书面同意，乙方及其员工、承包商、关联方不得：

1. **反编译、反汇编、逆向工程**本软件，或以任何方式尝试从目标代码中推导、还原、重建
   源代码、算法、业务逻辑或数据结构；
2. 修改、翻译、改编、二次开发本软件，或基于本软件制作衍生作品；
3. 复制、分发、出租、出借、转售、再许可本软件，或将其提供给约定范围外的任何第三方使用；
4. 移除、遮盖或更改本软件中的版权声明、商标、水印或其它权属标识；
5. 将本软件的目标代码、容器镜像或其中任何组件提取后用于约定经营目的以外的用途；
6. 规避、停用或干扰本软件内置的任何技术保护措施。

## 四、技术交付形态的确认

乙方确认并同意：

1. 本软件以**编译压缩后的容器镜像**形式交付，镜像内**不含**甲方的 TypeScript 源代码，
   亦**不含**可将运行代码还原为源代码的 source map 文件；
2. 镜像内的运行代码虽以编译压缩形态存在，但其本质仍为甲方的受保护作品。乙方对自有
   服务器的管理权限，**不构成**对镜像内代码进行第三条所列任何行为的授权；
3. 甲方保留通过技术手段进一步保护代码的权利，乙方不得干扰。

## 五、保密义务

本软件的目标代码、内部结构、算法、数据库设计均为甲方的商业秘密。乙方应采取不低于
保护自身同类信息的合理措施予以保密，且该义务在本协议终止后继续有效。

## 六、违约责任

乙方违反第三、四、五条任一约定的，应立即停止侵害、消除影响，并赔偿甲方因此遭受的全部
损失（含但不限于调查取证费、合理律师费）。情节严重的，甲方有权立即终止许可并追究其
法律责任。

## 七、其它

1. 本条款作为主合同（软件交付/服务合同）的组成部分，与主合同冲突时以主合同明确约定为准；
   主合同未约定的，以本条款为准。
2. 本条款适用中华人民共和国法律。因本条款引起的争议，双方应友好协商；协商不成的，
   提交甲方所在地有管辖权的人民法院诉讼解决。

      避免源码/密钥被打入镜像。

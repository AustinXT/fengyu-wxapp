计价边界：会议区分了既有数据中心、进销存的交付责任，以及新页面、目标填报、经营周期等新增需求。本次按指定 ¥25,000 编制新增与变更升级包，已有功能不重复计价，原交付缺陷按原约定处理。历史审计仅用于核验线索，不认定全部问题目前仍未修复。分析师旧合同余款及调整单独核对，本方案不自动抵扣、追收或认定历史结算结果。

#### 2.5.1 日报管理

原需求明确填写目标、日总结及规划；会议要求员工、门店、市场的经营目标与数据中心同源。下列草稿、提交状态及管理查询为完善日常使用提出的功能方案，具体表单以确认原型为准。

| 编号 | 功能项 | 功能内容 |
|---|---|---|
| R1 | 日报入口与身份范围 | 员工查看本人日报，店长查看授权门店，市场管理人员查看授权市场；与 PK 共用小程序登录、组织和导航 |
| R2 | 目标填报与关联 | 按人员、门店、市场及对应周期填写或关联经营目标；与数据中心使用同一权威来源，显示当前目标及完成情况 |
| R3 | 当日工作总结 | 按日期填写已完成工作、经营情况、问题与原因、需协助事项；以结构化字段和文字补充记录 |
| R4 | 后续工作规划 | 填写次日或下一阶段工作计划、重点跟进事项及预期目标，便于管理人员持续跟进 |

| R6 | 历史日报查询 | 按日期、填报人、门店和市场查询授权日报，查看历史总结与规划，支持按日回看 |
| R7 | 管理查看与提交统计 | 管理人员查看团队日报及已交／未交情况，结合目标完成值了解进度和待解决问题 |

验收重点：可完成目标关联、草稿保存、总结与规划填写、提交和历史查询；管理人员只能看到授权范围日报，提交统计可与人员名单核对；日报与数据中心同主体、同周期、同口径目标一致。

#### 2.5.2 分组 PK

# 凤御双小程序功能点清单

> 客户端（fengyu-client）与员工端（fengyu-staff）功能点汇总。

## 客户端（顾客端）

首页（轮播/热门/门店入口）、门店选择与详情（定位测距、绑定/解绑）、商城品项与规格、美容师、购物车；
下单与支付（微信/支付宝/线下/扫码、可预约识别）、订单列表/详情/取消；
预约（创建/列表/取消）、服务记录、疗程卡；
储值卡及流水、充值下单、积分（余额/等级/流水）、优惠券、体验卡、会员权益与分享礼；
个人中心、资料编辑、消息（列表/已读/未读数）；
微信登录、绑定手机号、绑定门店（来源/推广员）。

## 员工端

工作台（今日分成/业绩日历/6 种待办）
开单（仅店长：商品浏览/购物车/3 步结算/订单/收款码/确认线下收款/关单重置）
护理服务（服务单列表/新建/开始完成取消/顾客确认）
预约（列表/详情/确认/到店核销）
顾客（分类统计/搜索/详情/付费订单/标签筛选/退换记录/备注/客户分配）
提成分配（保存删除/比例/待分配/智能建议）
我的（员工信息/绩效/头像/快捷导航）
微信登录、绑定手机号/门店、优惠券查询

# 日报使用流程事实核查

## 范围与证据边界

- 【记录】用户要求 Codex 与 Claude Code 讨论日报小程序、对应云函数与管理后台是否操作繁琐。本轮仅分析，不修改代码，不部署。
- 【观察】本轮查看当前 daily 分支代码，以及用户提供的员工首页、我的、PK、门店日报截图。
- 【未知】没有完整真机走查、真实员工填报计时、全链路云端追踪、多人并发测试。不能把界面长推定为实际填写时间，也不能把本地直连数据库耗时等同于手机响应时间。

## 员工填报

1. 【观察】report.wxml:7-13 自动展示业务及指标；每条业务默认展开反馈和后续跟进两个 textarea，均选填；还有整日行动、成长、计划及两个指导关系选择。10 条业务会产生 20 个业务文本框，这是界面数量推算而非实际使用样本。
2. 【观察】report.ts:43-65 先 await report.read，再 await contacts.list，随后 ready=true；联系人加载失败会进入整个加载错误分支。
3. 【观察】report.ts:80-82、152-168 输入只更新页面状态并开启离开提醒；没有自动保存逻辑。report.ts:186-225 保存草稿及提交由手动触发。
4. 【观察】report.ts:53-55 联系人默认取本份报告保存的员工编号；新报告为空。report.wxml:13 为普通 picker，无搜索框。云函数 contacts.js:3-15 只允许选授权组织相关联系人，不是全体员工。
5. 【观察】report.ts:124-145 复制上次补充只复制行动、成长、计划；已有文本时先确认覆盖。不复制指导关系和业务反馈。
6. 【观察】report.ts:236-245 提交前有确认对话框；当日已提交报告的修改需要再次提交。

## 目标与 PK

7. 【观察】goal.wxml:9-46 同页含五项月目标、历史参考、个人负激励、当前周五项目标及全部周安排；月目标确认后不能编辑，当前周可保存，第4周自动取余额。
8. 【观察】pk.ts:17-35 初次读取周期再读取班级；selectedClass 后才读榜单。单个班级仍需要点选。
9. 【观察】pk.ts:66-70 指标切换会重新 load，进而查询 pk.classes 和 pk.read。pk.read 返回行中已含两种金额指标。pk-rules.js:25-48 排名按所选指标周完成率排序，无目标置后，同率保持输入顺序；本地改变显示字段而不重算排名将产生错误。
10. 【观察】routes/pk.js 已接入 query-with-jit-disabled，只在该查询的只读事务中关闭 JIT。进入班级仍需服务端校验，进入后读取完整班级。

## 管理者查看

11. 【观察】home.wxml:9-15 管理首页同时展示概况、待关注市场/门店/员工；workbench.wxml 同时提供组织树及人员搜索，组织树也显示门店提交统计。
12. 【观察】manager.wxml 员工卡片点击后进入个人经营月日报历史，history.wxml 再进入单日日报；门店页也另有已提交日报列表可直达详情，不能断言所有查看路径都必须经过个人历史。
13. 【观察】manager.ts:34-47 本轮此前已合并为一次 manager.list；routes/manager.js:13-33 返回授权门店与列表，并保留 assertStore；只返回已提交报告。
14. 【观察】routes/management.js:7-20 校验授权节点，39-65 一次返回组织、门店和员工统计，页面列表无分页。数据规模扩大后性能变化尚未验证。
15. 【观察】我的页此前已移除员工编号和历史入口，员工显示本人日报范围，支持多工作台切换。不能继续将已删除入口列为待修改问题。

## 后端与后台

16. 【观察】routes/report.js:93-111 保存使用事务、员工日期 advisory lock 及版本冲突检查；已提交报告不能执行草稿保存，历史提交不可修改。
17. 【观察】routes/report.js:113-158 保存会校验业务归属和联系人，提交时抓取指标快照。自动保存若调用既有保存接口，会涉及版本、业务变化和已提交状态约束。
18. 【观察】settings/daily/configuration.tsx:195-223 后台可以门店搜索/区域筛选，逐行设置班级、军团和指导员，指导员 datalist 来源为全体员工。保存 PK 配置需要 expectedVersion（119-124）；当前门店分配区没有批量选择控件。
19. 【观察】后台指导员存 mentorName 字符串；小程序指导关系存员工编号，contacts.validate 校验可选范围；这是两个不同来源，尚不能认定两者是同一种关系或应自动继承。
20. 【观察】日报汇总后台 view.tsx:130-192 提供单日/员工/区域门店筛选、报告内容展开与 Excel 导出。这与提交统计关注点不同。

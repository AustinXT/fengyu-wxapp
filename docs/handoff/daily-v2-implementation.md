# 日报 V2 完整实现清单

日期：2026-10-03。分支：daily（daily-v2 已按用户要求合并并删除）。目标：实现 `daily-report/daily-summary-miniapp-v2.html` 的小程序页面、交互及真实后端；不能以已有最小闭环代替完整交付。

## 原型依据

以 V2 HTML 当前的页面函数和事件处理为准。旧版方案中的“PK不在日报范围”不覆盖新版原型：V2 已有 PK 班级和两类榜单，纳入交付。浏览器 localStorage、固定日期、虚构金额、示例姓名、演示组织及手机状态栏均不是生产规则或业务数据。

## 不能用演示数据替代的部分

- 使用真实当前日期及已配置经营月；无配置显示空状态，不能默认编造26日至25日规则。
- 目标和配置存后端；未设置与零金额区分，金额以分计算。
- 去年同期无可映射配置／真实业绩时显示无数据。
- 历史应提交人数与日期需明确人员在职边界；不能把当前在职名单冒充历史出勤。
- PK成员只暴露授权范围；不直接把跨市场班级所有员工开放给普通账号。
- 首期旧日报回读保持兼容，无经营快照时不补造历史金额。

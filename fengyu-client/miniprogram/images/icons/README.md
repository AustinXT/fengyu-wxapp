# TabBar 图标说明

## 配色方案（黑金主题）

根据凤御 Logo 提取的品牌色：

| 颜色 | 色值 | 用途 |
|------|------|------|
| 品牌黑 | `#000000` | Logo 背景、深色区域 |
| 香槟金 | `#D4A76A` | Logo 主色、选中态、强调色 |
| 未选中灰 | `#8E8E93` | TabBar 未选中图标 |

# 五项目标与 Web 经营进度实现记录

本次用户已批准五项月周目标、区域独立进度、五项 Web PK、配置及 dev 验收。实现保留现有经营周期、负激励、班级入口和小程序双榜。

## 已实现

- 月目标增加客量、新客、项目数（可空、非负整数）。首次五项确认；旧金额继续锁定，可单独确认三项计数。旧两项请求保留兼容，不清空既有计数周目标。
- 第 1—3 周仅当前周可写，分别校验五项累计；第 4 周自动取余额；前三周缺值保持未设置，零目标不计算完成率。
- 有效服务按已完成且非寄存退款统计。员工按参与记录去重服务单、顾客、项目；项目数累加核销次数。首次到店查完整可用历史，市场新客直接按顾客去重。
- PK 对应个人、所属门店、本人市场目标，管理岗位不再配个人目标与整店实际。无门店或明确班级归属不会自动加入其他门店。多角色查看范围只展开实际授予数据查看动作的角色。
- Web 路由：`/data-center/operating-progress`（员工／门店／区域；周日列／月四周列；五项／全部），`/data-center/operating-targets`（本人、本人管理店／市场），`/data-center/operating-pk`（五项、六列、正逆序、筛选和导出）。
- 页面及 XLSX 使用同一份服务端授权查询结果，检索、指标选择和顺序一致；20 条分页。后台使用现有导航、Input、Button、Pagination、ExportButton、品牌及边框变量。
- 配置移除重复小组输入，显示组织档案区域；旧 group_name 列和既有值保持兼容。
- 小程序 PK 仍只展示业绩／消耗，保留六项周月数据、班级、军团／区域及正逆序。

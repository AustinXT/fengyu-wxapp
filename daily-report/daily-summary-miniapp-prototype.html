轻量日总结小程序新版原型

围绕“每天写总结、按权限看提交”形成轻量闭环。首页看今日状态和经营背景，填写页只负责快速提交；店长、市场总监、品牌总部按权限查看提交记录。经营数据只做辅助展示，不替代原经营端报表。

填写内容：行动 + 成长 + 计划 首页展示：月 / 周指标切换 权限逻辑：同页不同范围
可点击主流程

可点击原型

这台手机使用假数据模拟真实流程：切换角色后，首页、底部 tab、提交统计和下钻路径会跟着变化。

员工：总结 → 填写 → 保存草稿 / 提交 → 记录 → 详情。 店长：总结 / 填写 / 记录 / 我的；记录先看本店提交，再点员工看日总结。 管理层：首页 → 市场筛选 / 门店 → 员工记录 → 日报详情。
